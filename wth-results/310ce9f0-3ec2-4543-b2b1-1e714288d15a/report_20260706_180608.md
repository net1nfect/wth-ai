## Next Steps (Rekomendasi Sebelum Assessment Dimulai)

### Prioritas Immediate

```
STEP 1 — Siapkan Test Accounts
  Minimal:
    - userA: akun reguler (role: mahasiswa/user biasa)
    - userB: akun reguler kedua (role sama, data berbeda)
    - userAdmin: akun dengan privilege lebih tinggi (jika tersedia)
  Format scope: accounts=userA:pass,userB:pass

STEP 2 — Jalankan Passive Recon
  /recon passive sso.ssc.sevimaplatform.com
  Target output:
    - Subdomain enumeration (*.sso.ssc.sevimaplatform.com)
    - DNS records
    - Certificate transparency logs
    - HTTP headers baseline

STEP 3 — Build Asset Graph
  /graph build dari output recon
  Petakan: endpoint, parameter, auth flow, token mechanism

STEP 4 — Jalankan Hypothesis Engine
  Prioritas sesuai konstitusi:
    1. Auth bypass (SSO = target utama)
    2. Token/session manipulation
    3. IDOR pada resource SSO
    4. SSRF via redirect/callback
    5. Misconfig (CORS, CSP, cookie flags)
    6. Info leak (error messages, headers)

STEP 5 — Execute dengan Rate Limit 2 RPS
  /execute --rate-limit=2 --mode=standard
  Simpan semua output ke evidence vault [EV:...]
```

# Arsip dokumen perencanaan

Dokumen di direktori ini adalah **arsip keputusan**, bukan rujukan kerja. Rujukan
kerja tunggal ada di `.hermes/plans/` (rencana aktif) dan kode itu sendiri.

Kenapa dipisah: rencana lama memuat angka kondisi repo yang sudah tidak benar
(357 passed / 96 failed), daftar modul yang sekarang sudah dipulihkan, dan
urutan prioritas yang sudah dijalankan. Membacanya sebagai kebenaran sekarang
akan menghasilkan pekerjaan ganda.

## Aturan pemakaian

1. Jangan mengutip angka dari arsip ini sebagai kondisi terkini.
2. Kalau sebuah keputusan di arsip bertentangan dengan kode, kode menang —
   kecuali arsip menyebut alasan eksplisit yang masih berlaku (mis. larangan
   membuat dashboard pada `AGENTS.md`).
3. Tambahkan dokumen ke sini hanya setelah digantikan oleh rencana yang lebih
   baru, dan sebutkan penggantinya di baris pertama dokumen itu.

## Isi

Belum ada dokumen yang diarsipkan. Ketika rencana v2 selesai, file rencana
sebelumnya dipindahkan ke sini dengan catatan pengganti.

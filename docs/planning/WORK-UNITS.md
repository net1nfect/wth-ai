**KOREKSI dari P1 exit review (self-adversarial, didokumentasikan bukan disembunyikan)**: cut WU-116 pertama membuat `FALSE_POSITIVE` **terminal simetris** (memblok `FALSE_POSITIVE→VERIFIED` juga).
